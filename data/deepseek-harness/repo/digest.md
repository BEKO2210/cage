### Run
### Run from `npm`
Install `Node.js`, then run: The command starts the Web UI at `http://127.0.0.1:3080` by default and opens it in the default browser for a local launch.
```
npx @deepseek-ai/dsh web
```
### Run from source
To run from a repository checkout: `pnpm run build` prepares the repository artifacts.
```
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
...
```
