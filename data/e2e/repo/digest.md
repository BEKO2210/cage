### e2e
e2e is an end-to-end testing framework for web and mobile apps.
```

```
### Quick start
`init` asks for an engine, web or mobile, and a model provider, then writes a config and an example test.
```
npx e2e init
```
### Packages
| Package | What it does |
| `e2e` | The SDK, runner, and CLI. |
| `@e2e-dev/web` | Browser engine: Chromium, Firefox, and WebKit through Playwright. |
| `@e2e-dev/mobile` | iOS and Android engine: simulators and emulators through agent-device. |
| `@e2e-dev/github` | Reporter that posts results as a pull request comment. |
| `@e2e-dev/kernel` | Kernel hosted browsers for the web engine. |
|...

### Telemetry
The CLI sends anonymous usage data, such as which commands and engines run and where runs fail, but no test content, app content, or credentials.
