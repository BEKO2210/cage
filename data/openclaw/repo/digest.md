### OpenClaw 🦞 — Your assistant, on your devices, in your chats
OpenClaw is an open-source AI assistant that runs on your own computer and meets you in the channels you already use: Discord, iMessage, Slack, Teams, Telegram,
### Install
The installer supports macOS, Linux, and Windows.
```
# macOS / Linux / WSL2
curl -fsSL https://openclaw.ai/install.sh | bash
```
```
# Windows PowerShell
iwr -useb https://openclaw.ai/install.ps1 | iex
```
### Quick start
On a fresh install, the installer scripts start onboarding automatically.
```
openclaw onboard --install-daemon
```
```
openclaw gateway status
openclaw dashboard
```
